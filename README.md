 # Nombre del Proyecto: Best Cars Dealership


**Nombre del repositorio:** xrwvm-fullstack_developer_capstone


Aplicación web para concesionarios de autos construida con Django, React,
Express/MongoDB y un microservicio de análisis de sentimiento. Incluye
registro e inicio de sesión de usuarios, listado y filtrado de concesionarios
por estado, reseñas con análisis de sentimiento, y despliegue automatizado
con GitHub Actions.
